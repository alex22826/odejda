# odejda — интернет-магазин одежды

Витрина магазина одежды и небольшая панель управления. Чистые HTML/CSS/JS без сборки, серверная часть — один PHP-файл.

## Что есть

**Главная страница** (`index.html`)
- баннер-слайдер с автопрокруткой, свайпом и плашкой товара;
- разделы-категории, каталог с фильтрами, поиском, сортировкой и «Показать ещё»;
- карточка товара: галерея, цвет, размер, наличие; быстрые размеры при наведении;
- «Образ недели» — фото с точками-товарами и кнопкой «весь образ в корзину»;
- лента хитов, акция с таймером, блок «О магазине», контакты с картой;
- избранное, корзина (смена размера/цвета, бесплатная доставка от суммы) и оформление заказа.

**Панель управления** — открывается по адресу `<сайт>/admin26` (ссылки на сайте нет)
- товары: добавление, редактирование, копия, скрытие, удаление, загрузка фото (сжимаются в браузере);
- заказы со статусами «Новый / В работе / Выполнен / Отменён»;
- главная страница: слайды баннера, акция, точки «Образа недели» (ставятся кликом по фото);
- контакты, стоимость доставки;
- доступы: смена пароля, пользователи с ролями «Владелец» и «Менеджер»;
- экспорт и импорт каталога (резервная копия в JSON).

Логин — `admin`, пароль — в файле `ADMIN-ACCESS.txt` (лежит только локально, в git не попадает). Пароль можно сменить в разделе «Доступы».

## Два режима работы

Сайт сам определяет, есть ли сервер, по ответу `api/index.php?action=ping`.

| | Демо (GitHub Pages, локальный сервер) | Сервер (хостинг с PHP, например Beget) |
|---|---|---|
| Каталог и настройки | `assets/data/*.json` из репозитория | `storage/*.json` на сервере |
| Правки в админке | только в браузере админа (localStorage) | сразу видят все покупатели |
| Заказы | сохраняются в браузере покупателя | приходят в админку |
| Фото | хранятся в браузере | папка `uploads/` |

**Как опубликовать правки в демо-режиме:** в админке нажать «Экспорт», переложить товары и настройки из файла в `assets/data/products.json` и `assets/data/settings.json` и сделать push.

### Размещение на PHP-хостинге

1. Скопировать все файлы проекта в папку сайта (`public_html`).
2. Убедиться, что папки `storage/` и `uploads/` доступны для записи (обычно уже так).
3. Открыть `<сайт>/admin26`, войти и сменить пароль.

Подходит PHP 5.6–8.5, без баз данных и расширений. Данные — JSON-файлы в `storage/` (закрыты `.htaccess`), запись идёт под блокировкой, цены в заказе сервер пересчитывает по каталогу сам.

## Структура

```
index.html              главная страница
assets/css/style.css    стили витрины
assets/js/store.js      слой данных: API или localStorage
assets/js/shop.js       логика витрины
assets/data/            стартовый каталог и настройки
assets/img/, fonts/     фото (WebP) и шрифты — локально, без внешних CDN
admin26/                панель управления
api/index.php           серверная часть
storage/, uploads/      данные и фото на сервере (в git только .htaccess)
```

## Запуск локально

```bash
python -m http.server 8780
```

Затем открыть http://localhost:8780 и http://localhost:8780/admin26.

## Что заменить перед запуском

- Контакты, адрес, координаты карты — в админке, раздел «Контакты».
- Товары, цены, описания — демонстрационные.
- Фото — с [Pexels](https://www.pexels.com/license/) (бесплатная лицензия), замените на свои съёмки.
